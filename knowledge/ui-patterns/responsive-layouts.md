# Responsive Layouts

## Requirements

- mobile layouts should prioritize the primary workflow
- desktop layouts can add supporting summaries, sidebars, and secondary panels
- controls must not overflow their containers
- interactive targets should remain easy to tap on mobile
- repeated elements should have stable dimensions

## Review Checklist

- test narrow mobile width
- test tablet-ish width
- test desktop width
- verify text does not overlap controls
- verify primary actions remain visible
