# Pricing Tables

## Use When

A marketing surface (landing page, SaaS site, membership page) needs to present plan tiers and drive a choice.

## Expected Components

- 2-4 tier cards with name, price, cadence, and a concrete feature list
- exactly one visually highlighted tier (border/ring + "Most popular" badge)
- a CTA button per tier, with the highlighted tier's CTA strongest
- optional cadence toggle (monthly/yearly) that updates displayed prices

## Behavior

- feature lists state real capabilities, not adjectives; align comparable rows across tiers
- the highlighted tier never relies on color alone — pair it with a badge
- prices are display data; do not wire checkout, billing, or payment providers unless requested
- tiers stack to a single column on mobile with the highlighted tier first

## Avoid

- more than one highlighted tier
- "Contact us" on every tier
- feature lists that repeat the same line in every column
- dark-pattern anchoring (fake strikethrough prices)
