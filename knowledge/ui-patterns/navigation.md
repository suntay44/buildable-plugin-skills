# Navigation

## Use When

The prototype has more than one top-level area or a multi-step flow.

## Requirements

- Single-screen prototypes do not need heavy navigation.
- Use tabs for peer views.
- Use step indicators for booking/onboarding flows.
- Use sidebar navigation only when there are several persistent product areas.
- Keep current location visible.
- On mobile, prefer simple top headers or bottom tabs when there are true top-level sections.
