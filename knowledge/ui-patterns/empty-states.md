# Empty States

## Use When

A list, table, board, filter result, or dashboard region has no records to show.

## Requirements

- explain what is empty
- provide the next useful action
- distinguish first-use emptiness from filtered emptiness
- avoid generic placeholder copy

## Examples

- First-use task manager: invite the user to create the first task.
- Filtered task manager: explain that no tasks match the current filters and offer to clear them.
