# Filters

## Use When

The user needs to reduce a list, table, dashboard, catalog, or task board.

## Expected Components

- segmented status controls for small fixed sets
- search input for text filtering
- select/menu controls for larger option sets
- visible count of filtered results when useful

## Behavior

- filters should combine predictably
- empty state should reflect the active filters
- clearing filters should be obvious
- filters must work on mobile without horizontal overflow
