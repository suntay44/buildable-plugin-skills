# Action Bars

## Use When

A screen has repeated actions such as create, edit, filter, export, save, or bulk update.

## Requirements

- Put the primary action first or most visually prominent.
- Keep destructive actions separated from routine actions.
- Use stable button sizes to avoid layout shift.
- On mobile, wrap actions or collapse secondary actions instead of overflowing.
- Keep action labels specific: `Add task`, `Save lead`, `Confirm booking`.
