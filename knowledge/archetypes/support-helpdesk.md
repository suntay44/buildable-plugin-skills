# Support Helpdesk Archetype

## Purpose

A helpdesk helps users triage support tickets, priorities, statuses, and response drafts.

## Default Screens

- ticket queue
- ticket detail

## Default Entities

- Ticket
- Customer

## Required Interactions

- ticket list
- status/priority filters
- detail panel
- reply draft
- empty state

## Do Not Add Unless Requested

- email sending
- live chat
- accounts
- database
