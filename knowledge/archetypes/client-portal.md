# Client Portal Archetype

## Purpose

Show clients project status, milestones, files, and next actions.

## Default Screens

- `overview`: project summary, milestones, recent updates.
- `project detail`: deliverables, files preview, and next actions.

## Entities

- `ClientProject`: name, status, milestone, owner, dueDate.

## Required Interactions

- Inspect project details, filter updates, and show next action states.

## Do Not Add Unless Requested

- Client accounts, file uploads, billing, contracts, or external integrations.
