# Fitness Tracker Archetype

## Purpose

A fitness tracker helps users log workouts, sets, reps, history, and progress.

## Default Screens

- today
- history

## Default Entities

- Workout
- Exercise

## Required Interactions

- log workout
- sets/reps entry
- history list
- progress summary
- empty state

## Do Not Add Unless Requested

- wearable integrations
- accounts
- notifications
