# Time Tracker Archetype

## Purpose

A time tracker helps users log work sessions, projects, billable time, and summaries.

## Default Screens

- timer
- entries

## Default Entities

- TimeEntry
- Project

## Required Interactions

- start/stop timer
- manual entry
- project filter
- summary totals
- empty state

## Do Not Add Unless Requested

- team timesheets
- invoicing
- database
