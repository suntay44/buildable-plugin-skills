# Calendar Planner Archetype

## Purpose

Plan events, agendas, and date-based work without requiring external calendar integrations.

## Default Screens

- `calendar`: month/week overview plus agenda list.
- `event detail`: selected event details, status, and notes.

## Entities

- `CalendarEvent`: title, date, time, status, category, notes.

## Required Interactions

- Browse dates, inspect event detail, filter agenda items, and show an empty-day state.

## Do Not Add Unless Requested

- Google Calendar sync, team calendars, notifications, or hosted scheduling.
