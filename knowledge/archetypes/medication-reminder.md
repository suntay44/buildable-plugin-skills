# Medication Reminder Archetype

Build a mobile medication schedule prototype for tracking doses, reminder states, and medication details.

## Core Shape

- Today doses screen grouped by time with taken, missed, and snoozed states.
- Medication detail screen with dosage, schedule, notes, and refill reminder placeholder.
- Empty schedule state for adding the first medication.

## Local-First Rules

- Keep data local/mock by default.
- Do not provide medical advice, dosage recommendations, pharmacy integrations, push notification setup, accounts, or cloud sync unless explicitly requested.
- Include clear disclaimers in app copy when appropriate: the prototype tracks user-entered schedules only.
