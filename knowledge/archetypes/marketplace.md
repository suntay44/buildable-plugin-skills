# Marketplace Archetype

## Purpose

A marketplace connects buyers and sellers through listings, search, discovery, and inquiry or checkout flows.

## Default Screens

- listing browse
- listing detail
- inquiry or cart flow depending on prompt

## Default Entities

- Listing
- Seller
- Category
- Inquiry

## Required Interactions

- browse listings
- search and filter
- inspect details
- save or inquire

## Do Not Add Unless Requested

- payments
- user accounts
- seller dashboards
- reviews
- maps
- hosted database
