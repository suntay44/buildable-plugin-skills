# Notes Archetype

## Purpose

A notes or knowledge app helps users capture, organize, retrieve, and connect written information.

## Default Screens

- note list
- note editor
- search or tag view

## Default Entities

- Note
- Tag
- Collection

## Required Interactions

- create note
- edit note
- delete note
- search notes
- filter by tag or collection
- show empty state

## Do Not Add Unless Requested

- accounts
- sync
- collaboration
- AI summarization
- hosted database
