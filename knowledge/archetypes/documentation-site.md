# Documentation Site Archetype

## Purpose

Present structured product, developer, or API documentation.

## Default Screens

- `docs home`: topic overview and quick links.
- `doc page`: sidebar navigation and content sections.

## Entities

- `DocPage`: title, section, body, order, relatedPages.

## Required Interactions

- Navigate sections, search or filter docs, and keep mobile navigation usable.

## Do Not Add Unless Requested

- Live API calls, hosted search, auth-gated docs, or deployment setup.
