# Real Estate Archetype

## Purpose

A real estate app helps users browse properties, filter listings, inspect details, and inquire.

## Default Screens

- browse
- property detail

## Default Entities

- Property
- Agent

## Required Interactions

- property cards
- search/filter listings
- property detail
- inquiry CTA
- filtered empty state

## Do Not Add Unless Requested

- maps
- mortgage integrations
- auth
- database
