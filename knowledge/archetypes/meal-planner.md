# Meal Planner Archetype

## Purpose

A meal planner organizes weekly meals, recipes, and grocery planning.

## Default Screens

- week plan
- recipe detail

## Default Entities

- Meal
- Recipe
- GroceryItem

## Required Interactions

- weekly plan
- recipe cards
- grocery list
- filters
- empty state

## Do Not Add Unless Requested

- nutrition APIs
- grocery delivery integrations
- database
