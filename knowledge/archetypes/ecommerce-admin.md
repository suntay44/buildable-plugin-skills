# Ecommerce Admin Archetype

## Purpose

An ecommerce admin app helps users manage products, inventory, orders, and operational status.

## Default Screens

- overview
- product list
- order list
- product editor or detail panel

## Default Entities

- Product
- InventoryItem
- Order
- Customer

## Required Interactions

- search and filter products
- update product or inventory status
- inspect orders
- show low-stock or attention states
- handle empty table/list states

## Do Not Add Unless Requested

- payment processing
- customer accounts
- live shipping integrations
- managed database
- hosted storefront
