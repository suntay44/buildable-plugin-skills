# Booking Archetype

## Purpose

A booking app lets users view services, choose time slots, and confirm appointments.

## Default Screens

- service selection
- availability picker
- booking summary

## Default Entities

- Service
- Provider
- AvailabilitySlot
- Booking

## Required Interactions

- select service
- choose date and time
- enter basic booking details
- show confirmation state

## Do Not Add Unless Requested

- payments
- accounts
- calendar sync
- notifications
- managed database
