# Blog CMS Archetype

## Purpose

A blog/CMS prototype helps users draft, organize, search, and preview written content.

## Default Screens

- post list
- editor

## Default Entities

- Post
- Category

## Required Interactions

- create/edit post
- draft/published status
- search posts
- filter by category
- empty state

## Do Not Add Unless Requested

- hosted CMS
- auth
- database
