# Portfolio Archetype

## Purpose

A portfolio presents work, case studies, skills, and contact paths for an individual or studio.

## Default Screens

- home
- work
- project detail

## Default Entities

- Project
- CaseStudy

## Required Interactions

- browse projects
- inspect case study preview
- filter by category when useful
- contact CTA

## Do Not Add Unless Requested

- CMS
- auth
- deployment
