# Directory Site Archetype

## Purpose

Browse structured local, vendor, resource, or business listings.

## Default Screens

- `directory`: searchable listing grid/list.
- `listing detail`: listing profile, category, details, and inquiry intent.

## Entities

- `DirectoryListing`: name, category, location, summary, tags, status.

## Required Interactions

- Search listings, filter categories, open details, and show empty states.

## Do Not Add Unless Requested

- User-submitted listings, payments, map APIs, accounts, or moderation tools.
