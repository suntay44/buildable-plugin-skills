# Maintenance Request Archetype

## Purpose

Track repair or facility requests with status and priority.

## Default Screens

- `requests`: request list with status filters.
- `request detail`: priority, notes, location, and timeline.

## Entities

- `MaintenanceRequest`: title, location, priority, status, requestedAt, notes.

## Required Interactions

- Create or inspect requests, filter status, update priority, and show empty states.

## Do Not Add Unless Requested

- Photo uploads, technician dispatch, notifications, or tenant accounts.
