# Invoice Manager Archetype

## Purpose

An invoice manager helps users track invoices, payment status, clients, and totals.

## Default Screens

- invoice list
- invoice detail

## Default Entities

- Invoice
- Client

## Required Interactions

- create invoice
- edit invoice
- status tracking
- search/filter invoices
- summary totals

## Do Not Add Unless Requested

- payment processing
- PDF generation
- email delivery
- accounting integrations
