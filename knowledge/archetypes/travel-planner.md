# Travel Planner Archetype

## Purpose

A travel planner organizes trips, daily itinerary items, places, and notes.

## Default Screens

- itinerary
- place detail

## Default Entities

- Trip
- Place

## Required Interactions

- day grouping
- saved places
- notes
- filters
- empty state

## Do Not Add Unless Requested

- maps
- booking APIs
- database
