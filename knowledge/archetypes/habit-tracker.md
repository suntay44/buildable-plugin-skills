# Habit Tracker Archetype

## Purpose

A habit tracker helps users define routines, check them off, and see progress over time.

## Default Target

Mobile if the prompt is ambiguous and mentions daily use, streaks, check-ins, or routines.

## Default Screens

- today
- habit detail
- progress

## Default Entities

- Habit
- CheckIn
- Streak

## Required Interactions

- create habit
- mark today's habit complete
- view streaks
- review weekly progress

## Do Not Add Unless Requested

- accounts
- push notifications
- social sharing
- subscriptions
