# Social Link Bio Archetype

## Purpose

Create a compact creator profile page with important links.

## Default Screens

- `profile`: profile header, featured link, link list, and social actions.

## Entities

- `Link`: label, url, category, featured, order.

## Required Interactions

- Display a polished mobile-first link page with clear link hierarchy.

## Do Not Add Unless Requested

- Link analytics, custom domains, account settings, or payment links.
