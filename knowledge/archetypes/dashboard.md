# SaaS Dashboard Archetype

## Purpose

A SaaS analytics dashboard helps users understand product, revenue, or operational metrics at a glance.

## Default Screens

- overview dashboard
- metric detail or table drilldown when requested

## Default Entities

- Metric
- TimeSeriesPoint
- Event
- Account

## Required Interactions

- date range selection
- metric cards
- charts
- data table
- empty/loading/error states for data regions

## Do Not Add Unless Requested

- live analytics ingestion
- managed database
- billing
- account management
