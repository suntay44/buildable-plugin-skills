# Bug Tracker Archetype

## Purpose

Triage issues, defects, and QA reports in a local workflow.

## Default Screens

- `issues`: issue list with severity and status filters.
- `issue detail`: reproduction notes, owner, status, and timeline.

## Entities

- `Issue`: title, severity, status, assignee, component, reportedAt.

## Required Interactions

- Filter issues, change status, inspect details, and show empty states.

## Do Not Add Unless Requested

- GitHub/Jira sync, user accounts, notifications, or release automation.
