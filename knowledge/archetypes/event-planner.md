# Event Planner Archetype

## Purpose

An event app presents event details, agenda, sessions, speakers, and RSVP actions.

## Default Screens

- event home
- agenda

## Default Entities

- Event
- Session
- Speaker

## Required Interactions

- agenda list
- speaker cards
- session filters
- RSVP CTA
- mobile layout

## Do Not Add Unless Requested

- ticketing
- payments
- maps
- notifications
