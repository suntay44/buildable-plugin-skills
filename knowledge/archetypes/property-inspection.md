# Property Inspection Archetype

Build a mobile inspection checklist for walkthroughs, condition notes, issue tracking, and completion summaries.

## Core Shape

- Inspection checklist grouped by room/area.
- Item status controls such as pass, issue, not checked, and not applicable.
- Issue detail state with severity, notes, and photo placeholder.
- Completion summary with remaining issues and next action.

## Local-First Rules

- Use local checklist and issue seed data.
- Do not add camera permissions, storage uploads, maps, signatures, cloud sync, or dispatch integrations unless explicitly requested.
