# Membership Directory Archetype

## Purpose

Browse members, profiles, categories, and membership status.

## Default Screens

- `directory`: member list with search and filters.
- `member detail`: profile, category, contact intent, and notes.

## Entities

- `Member`: name, role, category, location, status, joinedAt.

## Required Interactions

- Search members, filter categories, open profiles, and show empty states.

## Do Not Add Unless Requested

- Member accounts, private messaging, dues payments, or CRM sync.
