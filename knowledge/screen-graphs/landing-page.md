# Landing Page Screen Graph

```txt
home (single scroll page)
  -> hero (value proposition + primary CTA)
  -> features (3-6 concrete benefits)
  -> social proof (testimonials / logos)
  -> pricing (tiers with one highlighted)
  -> faq (optional)
  -> closing CTA + footer (nav, legal)
```

## Required States

- first viewport communicates the offer without scrolling
- responsive nav: inline links on desktop, disclosure menu on mobile
- pricing tier hover/selected emphasis
- footer with real link groups (product, company, legal)

## Notes

- One page, no routing beyond anchor links.
- A hint of the next section should be visible at the fold.
- Anchor navigation must scroll smoothly and remain keyboard accessible.
