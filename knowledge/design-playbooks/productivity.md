# Productivity Design Playbook

## Tone

Focused, calm, and useful. The app should feel ready for repeated daily use, not like a marketing page.

## Layout

- usable first screen
- compact but breathable spacing
- task entry near the task list
- visible progress or workload summary
- clear difference between active and completed items

## Typography

- concise headings
- readable body text
- no oversized hero type inside tool surfaces

## Color

- use color to communicate priority, status, and selection
- avoid one-note palettes
- keep destructive actions visually distinct but not loud

## Common Mistakes

- generic placeholder tasks
- decorative cards that do not help workflow
- hidden edit/delete actions on mobile
- completed tasks that still look active

## Quality Bar

- task list, composer, filters, and stats should feel like one workflow
- sample tasks should demonstrate the full state range
- badges should communicate status or priority, not decoration
- mobile task actions must remain visible without hover
