# Block: Mobile Empty State

Use when a mobile screen can start empty, become filtered empty, or temporarily lose local/offline data.

Fit:

- first-run screens
- no matching filters/search results
- offline/local save recovery

Bind to the app spec:

- Keep copy short and useful.
- Provide one obvious recovery action.
- Use screen-appropriate spacing; do not push primary actions below the fold.
- Include filtered-empty and error variants when the workflow supports filters or saving.

Avoid:

- long instructional text
- empty artwork replacing the core action
- generic "Nothing here" copy
