# Block: Mobile Bottom Action Bar

Use when a mobile screen has one dominant action that should stay thumb-reachable.

Fit:

- add task, book appointment, save expense, complete job, log habit
- review/confirm screens

Bind to the app spec:

- Keep one primary action dominant.
- Respect safe areas and avoid covering list content.
- Include disabled, loading/saving, and success/error states.
- Pair with a secondary action only when it is truly needed.

Avoid:

- stacking many buttons at the bottom
- hiding destructive actions in the primary slot
- floating controls that overlap important content
