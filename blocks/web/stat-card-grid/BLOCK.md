# Block: Web Stat Card Grid

Use when users need an at-a-glance summary before working through records.

Fit:

- dashboards
- CRM pipeline summaries
- ecommerce/admin totals
- inventory risk and stock summaries

Bind to the app spec:

- Use 3-5 metrics directly derived from local mock data.
- Prefer plain labels and domain units over vague "Total" cards.
- Add trend, status, or comparison only when the sample data supports it.
- Keep cards compact; they support the workflow, they do not replace it.

Avoid:

- decorative metrics that do not connect to the app's main entity
- fake percentages with no obvious source
- oversized hero cards inside operational apps
