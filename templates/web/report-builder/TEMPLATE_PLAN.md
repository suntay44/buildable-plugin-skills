# Report Builder Planned Template

Use this pack when a prompt asks for reports, report builders, analytics builders, saved views, or exportable reporting workspaces.

## Build Shape

- Report workspace with saved views, filters, date range, and preview blocks.
- Block library with table, metric, and chart placeholders backed by local mock data.
- Saved reports list with status, owner, updated date, and empty state.

## Guardrails

- Keep data local/mock.
- Do not add warehouse connectors, export APIs, scheduled emails, dashboards-as-a-service, or BI integrations unless explicitly requested.
