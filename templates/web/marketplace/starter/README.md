# Buildable Marketplace Starter

A runnable, local-first services marketplace prototype (Next.js + TypeScript + Tailwind CSS, local state).

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run typecheck
npm run build
```

## What's Included

- Browse listings in a responsive card grid
- Search by service, location, or tag; filter by category; sort by rating or price
- Listing detail dialog with provider info
- Save / unsave listings
- Submit an inquiry with a confirmation state
- Filtered empty state with a clear-filters recovery action
- Meaningful sample data across several categories

All data is local state. No accounts, persistence, payments, or hosted services.
