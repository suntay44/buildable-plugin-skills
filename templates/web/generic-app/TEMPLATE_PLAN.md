# Web Generic App Template Plan

Use this planned template when an archetype has registry support but no dedicated web template yet.

## Product Shape

One polished local-first web prototype with a usable first screen, meaningful sample data, visible primary action, filters/search when useful, and empty states.

## Expected Structure

```txt
app/
components/
lib/
types/
```

## Validation Hints

- Do not copy unrelated templates.
- Use the selected archetype metadata from `core/archetype-registry.json`.
- Keep local/mock data by default.
- Run `buildable review` after implementation.
