# Property Inspection Planned Template

Use this pack for inspection checklists, walkthroughs, condition reports, and site audit mobile apps.

## Build Shape

- Checklist grouped by room, area, or section.
- Status controls for pass, issue, not checked, and not applicable.
- Issue detail with severity, notes, photo placeholder, and completion summary.

## Guardrails

- Keep checklist and issue data local/mock.
- Do not add camera permissions, uploads, maps, signatures, cloud sync, or dispatch integrations unless explicitly requested.
