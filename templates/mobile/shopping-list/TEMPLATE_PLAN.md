# Shopping List Planned Template

Use this pack for grocery lists, shopping checklists, and store-mode mobile utilities.

## Build Shape

- Quick-add list with quantity, category, and note fields.
- Grouped remaining/completed items with clear checked state.
- Store mode that prioritizes remaining items and keeps actions thumb-friendly.

## Guardrails

- Keep items local/mock.
- Do not add grocery APIs, barcode scanning, accounts, sync, or price comparison unless explicitly requested.
