# Medication Reminder Planned Template

Use this pack for medication schedules, pill trackers, and dose reminder prototypes.

## Build Shape

- Today doses grouped by time with taken, snoozed, missed, and upcoming states.
- Medication detail with schedule, dosage text entered by the user, notes, and refill placeholder.
- Empty schedule state for adding the first medication.

## Guardrails

- Keep schedule data local/mock.
- Do not provide medical advice, dosage recommendations, push notification setup, accounts, pharmacy integrations, or cloud sync unless explicitly requested.
