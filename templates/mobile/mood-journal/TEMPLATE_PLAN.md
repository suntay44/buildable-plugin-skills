# Mood Journal Planned Template

Use this pack for mood trackers, wellness journals, daily reflection apps, and feelings check-ins.

## Build Shape

- Today check-in with mood choice, tags, reflection prompt, and save state.
- History list grouped by date with simple mood summary.
- Gentle empty state and non-judgmental missed-day copy.

## Guardrails

- Keep entries local/mock.
- Do not make medical claims, diagnosis claims, crisis handling claims, accounts, cloud sync, or notification setup unless explicitly requested.
