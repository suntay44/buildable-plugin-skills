# Mobile Generic App Template Plan

Use this planned template when an archetype has registry support but no dedicated mobile template yet.

## Product Shape

One local-first Expo prototype focused on the primary mobile workflow, touch-friendly controls, meaningful sample data, and clear empty states.

## Expected Structure

```txt
app/
components/
lib/
types/
```

## Validation Hints

- Do not copy unrelated templates.
- Use the selected archetype metadata from `core/archetype-registry.json`.
- Keep local/mock data by default.
- Run `buildable review` after implementation.
