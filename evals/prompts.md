# Eval Prompts

Use these prompts to compare Buildable-guided generation against generic agent prompting.

## V1 Golden Prompts

```txt
Build me a todo app
Build me a CRM for tracking leads
Build me a mobile habit tracker
Build me a SaaS analytics dashboard
Build me a marketplace for local services
```

## Task Manager Variants

```txt
Build a simple task manager for a freelance designer
Create a polished todo app for managing weekly chores
Make a local-first project task tracker with priorities and filters
```

## Expected Task Manager Spec Highlights

- web target unless mobile requested
- task-manager archetype
- local state
- no auth
- one primary dashboard screen
- create, edit, delete, complete, reopen
- filters, search, sample data, empty state
